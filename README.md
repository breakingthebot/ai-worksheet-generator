# AI Worksheet Generator & Curriculum Studio

A daily learning studio and printable worksheet generator anchored in accredited curriculum standards (Eureka Math, Core Knowledge CKLA/CKHG, and NGSS). It organizes learning day by day with structured time blocks, hands-on activities, real-world field trip reinforcement quests, parent coaching scripts, and print-optimized 8.5×11 Letter worksheets with answer keys.

## How to Run It

### 1. Install Dependencies
```bash
npm install
```

### 2. Start the Development Server
```bash
npm run dev
```
Open your browser at `http://localhost:5173`.

### 3. Run Automated Tests
```bash
npm test
```

### 4. Build for Production
```bash
npm run build
```
